Super refers to window manager. Ctl is for application (if supported).

## System & Window Management
Super/Ctl + F → Toggle fullscreen
Super/Ctl + Q → Close active window
Super + Space → Toggle split layout
Super + Shift + Space → Toggle floating window
Super + P → Toggle pseudo layout (dwindle mode)
Super + S → Toggle special workspace “magic”
Super + Shift + S → Move window to special workspace “magic”
Super + Shift + R → Reload Hyprland

## Applications & Utilities
Super + Return → Launch terminal
Super + M → Open system menu
Super + D → Launch application launcher (again to close)
Super + E → Launch file manager (again to close)
Super + N → Open Neovim in new terminal window
Super + B → Focus or launch browser (Vivaldi)
Super + O → Focus or launch Obsidian
Super + W → Focus or launch WhatsApp
Super + C → Focus or launch ChatGPT
Super + Y → Focus or launch YouTube
Super + X → Focus or launch Excalidraw
Super + / → Focus or launch 1Password

## Focus Movement
Super/Ctl + H → Move focus left
Super/Ctl + J → Move focus down
Super/Ctl + K → Move focus up
Super/Ctl + L → Move focus right

## Window Movement
Super + Shift + H → Move window left
Super + Shift + J → Move window down
Super + Shift + K → Move window up
Super + Shift + L → Move window right

## Workspaces
Super/Ctl + [1–9, 0] → Switch to workspace 1–10
Super/Ctl + Shift + [1–9, 0] → Move active window to workspace 1–10
